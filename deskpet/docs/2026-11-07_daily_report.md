# DeskPet 工作日报 — 2026-11-07

## 今日目标与决定

围绕 Delta 做一个能在电脑桌面显示的个性化桌宠。先完成软件和动作调试，再连接 PetRing 或重新设计的动作检测项圈；最终希望是有 Delta 外形特征的写实 3D。桌宠表达可观察的行为，不推断情绪。

首版选择 macOS 和风格化 3D，以便先验证产品交互与事件接口。用户提供的照片用于本机参考；原始照片没有进入 Git 仓库。

## 当前边界

这仍是风格化的工程模型，不是照片自动重建的写实狗。脸部、毛发和趴姿还显得僵硬，动画是程序驱动的节点动作，尚未达到专业骨骼动画的质量。导入任意 USDZ 模型后，专用动作绑定也尚未自动适配。

目前没有硬件实时输入、跨公网事件服务、配对认证或断线重连；界面上的“实时”只在本地模拟或手动输入时完成验证。现有 PetRing 固件的回家上传是记录同步，不能直接等同于上班期间的实时陪伴。

## 下一步

1. 按 [项目 Proposal](../PROPOSAL.md) 先做可验收的软件版本：完善动作状态机、骨骼动画、模型轮廓和毛发，并保证事件中断时不显示旧状态。
2. 使用已有 ESP32 Feather 和 LSM6DSOX 采集 Delta 的标注数据，分别验证静止／走动、喝水和叫声；在得到误报数据前不承诺准确率。
3. 设计家中在线事件链路，再连接到桌宠。新增硬件或传感器由数据证明必要性后再决定。
