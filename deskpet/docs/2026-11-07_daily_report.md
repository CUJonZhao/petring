# DeskPet 工作日报 — 2026-11-07

## 今日目标与决定

围绕 Delta 做一个能在电脑桌面显示的个性化桌宠。先完成软件和动作调试，再连接 PetRing 或重新设计的动作检测项圈；最终希望是有 Delta 外形特征的写实 3D。桌宠表达可观察的行为，不推断情绪。

首版选择 macOS 和风格化 3D，以便先验证产品交互与事件接口。用户提供的照片用于本机参考；原始照片没有进入 Git 仓库。

## 已完成

| 工作 | 结果 |

## 当前边界

这仍是风格化的工程模型，不是照片自动重建的写实狗。脸部、毛发和趴姿还显得僵硬，动画是程序驱动的节点动作，尚未达到专业骨骼动画的质量。导入任意 USDZ 模型后，专用动作绑定也尚未自动适配。

目前没有硬件实时输入、跨公网事件服务、配对认证或断线重连；界面上的“实时”只在本地模拟或手动输入时完成验证。现有 PetRing 固件的回家上传是记录同步，不能直接等同于上班期间的实时陪伴。

## 下一步

1. 按 [项目 Proposal](../PROPOSAL.md) 先做可验收的软件版本：完善动作状态机、骨骼动画、模型轮廓和毛发，并保证事件中断时不显示旧状态。
2. 使用已有 ESP32 Feather 和 LSM6DSOX 采集 Delta 的标注数据，分别验证静止／走动、喝水和叫声；在得到误报数据前不承诺准确率。
3. 设计家中在线事件链路，再连接到桌宠。新增硬件或传感器由数据证明必要性后再决定。

## 晚间补充：Delta 模型重做（v2 → 头部 v3）

### 起因

下午那版模型是一堆球和圆锥拼起来的：耳朵边上有一串"手指"，身上能看到贴图接缝，表情也僵。晚上先把整只狗按照片重做了一遍（v2），然后按 Delta 是喜乐蒂的特征，以及主人提供的风格化示意图，把头部单独迭代到 v3。

### 已完成

| 工作 | 结果 |
|---|---|
| 建模流程 | 重写 `scripts/build_delta_model.py`。每个部位由基本体合并后做体素重建（voxel remesh）再平滑，得到一整块连续网格。花纹的做法：先烘焙每个像素对应的世界坐标，再用三维花纹函数逐像素上色。毛发用透明裁剪的毛片（hair cards）。动画用到的节点名保持不变。 |
| 身体（v2，主人确认还原度高） | 蓝陨石纹，背上有大块黑斑；白项圈、白胸、白前腿；后腿是陨石灰配白爪；尾巴蓬松，尾尖白色。身体用细毛片，约 9000 片。 |
| 头部（v3，按示意图） | 楔形头，吻部短，圆鼻头。白色鼻梁线一直通到头顶；两眼周围是黑眼斑，往下碎成黑白麻点，吻部两侧也有麻点。头顶两侧是向外翻的黑色毛簇，脸外圈是白色鬃毛，都用"雕塑羽状毛簇"贴图。双眼暂时改为普通黑眼睛：虹膜贴图带纹理，表面有光泽，加了发光的高光点。 |
| app 适配 | `PetSceneView.swift` 新增 `configureFurMaterials`：对 `fur_*` 材质开启双面显示、alpha 裁剪着色器和深度写入。舌头节点位置改为 `(0, -0.35, -0.115)`，与新的嘴部对齐。 |
| 构建脚本 | `build_app.sh` 改为每次先删除旧 app 包、再做本地临时签名（ad-hoc）。原来直接覆盖已启动过的二进制，会导致 `Launchd job spawn failed`。 |
| 迭代工具 | 新增 `scripts/render_watch.sh`：在终端里开着，往 `.work/request` 写入 `model`/`preview`/`all`/`app`，就会执行对应的固定任务。`render_delta_preview.py` 输出 7 个视角：app 视角、侧面、正面、左右 3/4 脸、正脸特写、俯视。参考照片放在 `reference_photos/`，`.work/` 和 `reference_photos/` 都已加入 `.gitignore`。 |

示意图与新头部的对比：[figures/2026-11-07_head_vs_sketch.png](figures/2026-11-07_head_vs_sketch.png)

### 验证

- Blender 5.2.2 每次生成加 7 视角渲染约 15 秒。模型约 8.2 万面，`Delta.usdz` 约 8.5 MB。
- 重新编译的 DeskPet 能加载新模型。在 app 里逐个点了待机、休息、喝水、叫声：毛片裁剪正常，下巴开合正常，没有部件散开。
- 每处花纹都和参考照片、示意图并排对照过。

### 当前边界

- 头部是风格化的，不是照片级写实。吻部侧面看仍偏长，麻点偏大。白色鬃毛在背光侧发灰。黑色毛簇边缘还有零散翘起的。
- 在 app 的灯光下整体偏亮。喝水动作里嘴和水碗之间还有距离。
- 眼睛暂时是黑色，还不是 Delta 真实的左右异色（右蓝左棕）。
