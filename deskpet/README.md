# DeskPet

macOS-first desktop pet prototype. It runs independently of PetRing hardware.

## What works

- A transparent, movable 3D pet window that stays above normal windows.
- A locally authored, stylized 3D Delta model (see below) with an articulated head, jaw, tail, and two-part legs. Rest turns once, folds the legs, lies down, and closes its eyes. Drink walks to a water bowl, lowers the head, laps with a visible tongue, and makes water ripples.
- Local import of reference photos, grouped by angle. Photos are copied to `~/Library/Application Support/DeskPet/` and are not committed to the repository.
- Import a USDZ scene to replace the built-in model. Rigged behavior animations for arbitrary imported scenes are not yet supported; whole-model state changes still work.
- Manual event simulation, a local mock gateway and a WebSocket event client for a future gateway.
- If live events stop for 15 seconds, the pet shows `unknown` instead of pretending to be live.

The built-in model is generated by `scripts/build_delta_model.py`. Each body part is one continuous remeshed surface; the coat is painted per pixel from a 3D marking function and covered with alpha-cut hair cards that `PetSceneView` renders double-sided with a cutout shader. The body keeps Delta's blue-merle coat from the reference photos (black back patches, white collar, chest and front legs, merle hind legs with white feet, white-tipped tail). The head follows the owner's stylised Sheltie sketch: a wedge head with a short muzzle, a wide white blaze to the crown, black eye patches breaking into speckles, black crown "wings" and a white mane ring built from sculpted feather-like fur clumps. Both eyes are temporarily plain dark eyes. It is stylised, not a photogrammetric reconstruction.

## Build

Requires macOS 14 or later and Apple Command Line Tools with Swift 5.10 or later.

```sh
cd deskpet
xcrun swift build
./scripts/build_app.sh
open .build/DeskPet.app
```

The editable model source is `Resources/Delta.blend`. To rebuild `Resources/Delta.usdz`, run `scripts/build_delta_model.py` in Blender 5.2 or later. `scripts/render_delta_preview.py` renders QA views (app framing, side, front, both face 3/4 views, top) into `.work/`. Reference photos go in `reference_photos/` (git-ignored); neither script uploads them.

To iterate without typing Blender commands, start `bash scripts/render_watch.sh` once; it runs only fixed jobs when `.work/request` contains `model`, `preview`, `all` or `app`.

To run a local event stream without hardware:

```sh
python3 scripts/mock_gateway.py
```

Then enter `ws://127.0.0.1:8765/events` in the app and click Connect.

## Event contract

The app accepts WebSocket text or binary JSON messages such as:

```json
{"state":"walk","confidence":0.9,"timestamp":"2026-11-07T16:00:00Z"}
```

`state` is `idle`, `rest`, `walk`, `drink`, `bark`, or `unknown`.
Messages with confidence below `0.6` are ignored. The gateway should send a state heartbeat at least every 10 seconds. The app uses its receive time for freshness, so a clock mismatch cannot make a stale status appear fresh. This is a development interface; pairing, authentication, reconnect and cloud relay remain for the hardware integration phase.
